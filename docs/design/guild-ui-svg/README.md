# 江湖世界 UI SVG 设计稿

基于 `docs/guild-world-design.md` 与 `ProvidersViewMockup.svg` 的中性卡片风格生成，未参考现有前端实现。

## 文件清单

| 文件 | 页面 |

| `00-guild-overview.svg` | 江湖总览 |
| `01-bounty-board.svg` | 悬赏榜 |
| `02-sect-detail.svg` | 门派详情 |
| `03-person-hero.svg` | 弟子 / 侠客 |
| `04-recruitment-hall.svg` | 聚贤庄 |
| `05-economy-market.svg` | 义仓经济与三阁市集 |

| `07-bid-adjudication.svg` | 竞价裁决 |
| `08-world-log-station.svg` | 江湖录与驿站 |

## 设计原则

- 背景、卡片、按钮、文字层级沿用 `ProvidersViewMockup.svg` 的 SaaS 管理台风格。
- 保留江湖术语，但视觉不做强古风皮肤。
- 重点显性化：悬赏榜、义仓、门派、弟子体征、聚贤庄、长约、驿站。
- 页面尺寸统一为 `1280 × 1280`，便于并排浏览与二次拆组件。
